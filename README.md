# Scry Fruit card images

This branch holds only card images, kept apart from `main` so the code's
history stays small. Each file is `<printing id>.webp`, 360 px wide.

They are shrunk copies of the images on Bandai's official card list
(en.onepiece-cardgame.com). Card art and text © Bandai / Eiichiro Oda.
Unofficial fan project.

Don't edit by hand: the weekly "Refresh card data" workflow adds images for
new printings (`scripts/images.ts` on `main`), and the deploy copies this
branch into the site's `img/` folder.
